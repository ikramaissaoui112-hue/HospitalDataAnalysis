\# Hospital Data Analysis



\## Project Description

This project analyzes a small dataset of hospital patients using Python.



\## Dataset

The dataset is stored in `data/patients.csv` and contains:

\- PatientID

\- Age

\- Sex

\- BloodPressure

\- Cholesterol

\- Diagnosis



\## Tools and Libraries

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Jupyter Notebook



\## Analysis

The notebook explores the dataset, calculates descriptive statistics, counts patients by sex and diagnosis, and visualizes cholesterol levels against age.



\## How to Run

1\. Install the required libraries.

2\. Open Jupyter Notebook.

3\. Run `notebooks/patients\_analysis.ipynb`.
